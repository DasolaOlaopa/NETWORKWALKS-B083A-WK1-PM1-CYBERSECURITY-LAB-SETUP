# NETWORKWALKS-B083A-WK1-PM1-CYBERSECURITY-LAB-SETUP

## Cybersecurity Lab Environmental Setup
An Isolated virtual lab built with VirtualBox and Kali Linux machine for cyberscurity testing and penetration testing. 
## 📌 Project Overview 
This project focuses on setting up a virtual cybersecurity and penetration-testing laboratory using VirtualBox and Kali Linux. The aim of the lab is to create a sandbox environment where cybersecurity tools, network scanning, reconnaissance, vulnerability assessment, and other security activities can be performed safely and frequently.
